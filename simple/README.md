# Простий замірник

Готовий автономний вебзастосунок українською. Відкрийте `index.html` або опублікуйте на статичному хостингу. Не потребує збірки, сервера чи залежностей.

- Гаражні та промислові ворота: ширина, висота, перемичка, лівий/правий заплічник, автоматика, колір 7016 за замовчуванням, примітка.
- Огородження: довільна кількість секцій; розпашні/відкатні ворота; хвіртка.
- Розміри — лише цифри, в міліметрах. Сторона відкату показується для відкатних воріт.
- Автозбереження одного об’єкта у localStorage браузера; категорії зберігаються окремо.
- Завантаження всіх даних JSON, друк / збереження PDF через браузер.
- Новий об’єкт очищує поточні дані після підтвердження.

Дані не надсилаються на сервер і не синхронізуються між пристроями. Перед очищенням браузера завантажте файл. Імпорту JSON у цій версії немає.

## GitHub Pages

У Settings → Pages виберіть Deploy from a branch → main → / (root) → Save. Після успішного розгортання застосунок буде за адресою https://Redd1ngton.github.io/wisniowski-zamirnyk/simple/ . У момент підготовки цієї версії Pages вимкнений; це очікувана адреса, не підтверджений активний сайт.

Попередній застосунок у корені репозиторію збережено.

## Перевірки

Перевірено синтаксис JavaScript та логіку фільтрації чисел, незалежність категорій, додавання секцій, поле сторони відкату та екранування тексту. Візуальна перевірка у браузері в цьому середовищі не виконувалась.
