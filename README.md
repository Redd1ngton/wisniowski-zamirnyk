# Замірник WIŚNIOWSKI — прототип PWA

Веб-застосунок-асистент для замірів гаражних воріт, систем огорожі та дверей WIŚNIOWSKI.

Призначений для менеджерів, які роблять заміри без монтажних спеціалістів. Збирає максимум технічної інформації + фото з підказками.

## Як запустити локально

1. Відкрийте `index.html` у браузері (або розмістіть на будь-якому статичному хостингу).
2. Для повноцінної роботи як PWA — краще через HTTPS (GitHub Pages ідеально підходить).

## Як встановити на телефон (без App Store)

### iPhone (Safari)
1. Відкрийте посилання на застосунок.
2. Натисніть кнопку «Поділитися» (квадрат зі стрілкою).
3. Оберіть «На екран „Додому“».
4. Підтвердіть. З’явиться іконка «Замірник».

### Android (Chrome)
1. Відкрийте посилання.
2. Натисніть меню (три крапки) → «Встановити застосунок» або «Додати на головний екран».
3. Підтвердіть.

Після встановлення відкривається на повний екран як звичайний додаток.

## Функціонал прототипу

- Вибір типу продукту (гаражні ворота UniPro/MakroPro, огорожа, двері).
- Покрокова форма: дані замовника → технічні заміри з підказками → фото → підсумок.
- Підказки як правильно міряти (ширина/висота в 3 точках, діагоналі, перемичка N, бічні відступи W1/W2 тощо).
- Обов’язкові категорії фото.
- Експорт: завантаження JSON з усіма даними.
- Готовий до розширення (Telegram-бот, генерація PDF, більше типів продуктів).

## Наступні кроки (поза прототипом)

- Повноцінна відправка архіву (ZIP з фото + JSON/PDF) через Telegram Bot API.
- Генерація заповненого бланку у PDF.
- Більше типів воріт/огорож з точними полями з бланків.
- Збереження чернеток локально (IndexedDB).
- Валідація розмірів за серіями WIŚNIOWSKI.
